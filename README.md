# 💬 Offline ChatGPT Clone (Ollama + Frontend)

A complete **ChatGPT-like offline chatbot** with:

- 🌐 Frontend (HTML, CSS, JavaScript)
- 🧠 Backend (Ollama local LLM)
- 📴 Fully offline — no API required

---

## 🚀 Features

- ChatGPT-style UI (dark theme)
- New Chat system
- Chat history sidebar
- Model selection (mistral, llama2, etc.)
- Fast local responses using Ollama
- Backend-ready architecture
- Microphone & File upload (UI only)

---

## 🧠 Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python / Node.js
- AI Runtime: Ollama (Local LLM)
